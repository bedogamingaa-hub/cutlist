# 🎮 بيدو درايف — شوارع مصر (BeDo Gaming APK)

ملف المشروع الكامل الجاهز للرفع على **GitHub** لتحويل اللعبة تلقائياً إلى تطبيق أندرويد خفيف **(`APK`)** بأيقونة وشعار **BeDo Gaming**.

## 🚀 خطوات استخراج ملف الـ APK من GitHub في دقيقتين:
1. فك الضغط عن هذا الملف `bedo-drive-apk-github.zip` على جهازك أو موبايلك.
2. ادخل على حسابك في **GitHub** واعمل مستودع جديد (**New Repository**) بأي اسم (مثلاً `bedo-drive`).
3. ارفع كل الملفات والمجلدات الموجودة هنا (بما فيها مجلد `.github` ومجلد `www` وملف `package.json` و `icon.png`) إلى المستودع واضغط **Commit changes**.
4. افتح تبويب **Actions** من أعلى صفحة المستودع في GitHub، ستجد عملية بناء التطبيق (**Build Bedo Drive Android APK**) تعمل تلقائياً.
5. بعد انتهاء البناء (حوالي دقيقتين)، اضغط على العملية وحمّل ملف **`BedoDrive-BeDoGaming-APK`** من قسم **Artifacts** وثبّت الـ `APK` على موبايلك مباشرة!
